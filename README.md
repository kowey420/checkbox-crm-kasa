# Каса для Checkbox

Проста облікова система (CRM) для роботи з [API Checkbox](https://wiki.checkbox.ua/uk/api):
веб-інтерфейс у браузері, локальна база товарів, продаж, зміни, термінал, журнал чеків.

> Незалежний проєкт, не є офіційним продуктом Checkbox.

## Можливості

- **Продаж** готівкою (із заокругленням до 50 коп. за правилами НБУ), карткою та «Іншою» оплатою з власною назвою
- **Платіжний термінал** через POSSrv (ПриватБанк PAX A930, Ощадбанк Ingenico): оплата й дані ЕПЗ у чек автоматично
- **Товари**: синхронізація з Checkbox, податкові ставки, акцизні марки, додавання й редагування —
  зміни одразу діють у касі й відправляються в Checkbox пакетом (кнопка, відкриття/закриття зміни):
  змінені товари — PUT /goods/{id} (поточний стан товару + правки, зокрема група), нові — POST /goods
  (або імпортом, якщо метод недоступний); помилка одного товару не зупиняє решту;
  «Залишковий товар» і залишок — у Checkbox ідуть поставкою через імпорт з автопоставкою (лише збільшення),
  після чого каса звіряє залишки з Checkbox
- **Телефон покупця**: копія чека в SMS/Viber (`delivery.phone`, формат 380…) — у продажі, передплаті, доплаті й поверненні
- **Плитки**: групи — папками, товари — картками зі значком (у касі й на вкладці «Товари»), перехід у підгрупи
  й назад («хлібні крихти», «Назад»), лічильник у кошику на плитці; перемикач «Плитки / Список»
- **Облік акцизних марок**: продана марка зберігається в локальній базі, і продати її вдруге (у тому числі
  з передплатою) каса не дасть — ні при скануванні, ні на сервері, — поки марку не повернуть чеком повернення
  (або поверненням замовлення); марка — рівно 10 символів. Марки з чеків інших кас — після «Завантажити з Checkbox». Перелік — «Товари» → «Акцизні марки»
- **Власні зображення плиток**: ПКМ по товару чи групі → «Встановити зображення…» (або перетягнути файл на плитку);
  картинка зменшується до 256 px і зберігається локально в папці `images` поруч із базою
- **Групи й підгрупи товарів** з Checkbox: у касі — перехід по групах над списком товарів (пошук — по всіх),
  на вкладці «Товари» — вибір групи і заголовки груп у таблиці; групи згортаються кліком;
  дерево груп з редагуванням одразу в Checkbox: створити, перейменувати, перенести, видалити, перенести товари
- **Сканування підряд** (кнопка «▦ Сканувати підряд» або F2): скан за сканом у кошик зі звуком, вага вагових товарів
  і акцизні марки прямо у вікні, «Прибрати останнє», потім одразу «Готівка» чи «Картка»
- **Знижки й надбавки** на товар і на весь чек — відсотком або сумою (у чек ідуть сумою, як радить Checkbox)
- **Повернення** з журналу за чеком продажу: вибір товарів і кількості, частковими частинами, з урахуванням знижок;
  готівкою або на картку — через термінал (команда POSSrv «Відміна / повернення» з RRN продажу та id пристрою) чи вручну
- **Передплата й післяплата**: чек передплати з усіма товарами кошика і внеском, доплати частинами,
  післяплата, що закриває замовлення (готівкою — із заокругленням і рештою), повернення всього замовлення;
  вкладка «Передплати» з чеками кожного замовлення. Картка — через термінал або вручну
- **Зміни**: відкриття, закриття з Z-звітом у PNG, X-звіт у PNG, залишок готівки в касі;
  службове внесення й винесення готівки; відкриття зміни прямо з вікна оплати
- **Чеки**: PNG чека після продажу з друком; журнал за 7 днів по днях і змінах (з Checkbox),
  з продажами, поверненнями, внесеннями й винесеннями
- **CSV**: експорт товарів для сайту, імпорт/перевірка, вивантаження й завантаження номенклатури Checkbox
- Значок у треї Windows (відкрити касу, папку з логами, поточний лог, вийти), автоматичний вибір вільного порту, журнал роботи у файлі, оновлення з GitHub

## Встановлення

### Windows — готова програма
Завантажте `Kasa.exe` з [останнього випуску](../../releases/latest) і запустіть.
Python не потрібен. Дані зберігаються в `%LOCALAPPDATA%\Каса Checkbox`
(або поруч із `Kasa.exe`, якщо там лежить `config.json`).

### Mac
Завантажте `Kasa-mac.zip` з [останнього випуску](../../releases/latest), розпакуйте,
перетягніть «Каса» в «Програми». Інструкція для першого запуску — у «Прочитай мене.txt» в архіві.

### Будь-яка система — через Python 3.9+
Завантажте `kasa-py.zip` (або склонуйте репозиторій) і запустіть:
- Windows — `Запустити касу.bat`
- macOS / Linux — `Запустити касу.command` або `python3 checkbox_web.py`

Сторонні бібліотеки не потрібні; для значка в треї Windows — `pystray` і `Pillow`
(`Запустити касу.bat` встановить їх сам).

## Налаштування
Відкрийте касу й натисніть **⚙ Налаштування**: ключ ліцензії каси, логін і пароль або пін-код касира,
заокруглення готівки, платіжний термінал. Приклад файлу — `config.example.json`.
`config.json` з паролями в репозиторій не потрапляє (див. `.gitignore`).

## Оновлення
Каса при запуску перевіряє [останній випуск](../../releases/latest) і показує банер
«Доступна нова версія — Оновити». Після натискання вона завантажує файл, звіряє контрольну суму
з `SHA256SUMS.txt`, робить резервну копію (`backup/` у папці даних) і перезапускається.
Перевірити вручну — **⚙ Налаштування → Перевірити оновлення**.

Репозиторій для оновлень задається в `checkbox_app.py`: `GITHUB_REPO = "власник/назва"`.

## Випуск нової версії
1. Змініть `APP_VERSION` у `checkbox_app.py`, наприклад `"1.1.0"`.
2. Закомітьте й надішліть зміни (`git commit -am "Версія 1.1.0" && git push`).
3. Запустіть випуск одним зі способів:
   - на GitHub: **Actions → «Випуск» → Run workflow** — тег `v1.1.0` створиться сам;
   - або тегом: `git tag v1.1.0 && git push origin v1.1.0`.
4. GitHub Actions (`.github/workflows/release.yml`) збере `Kasa.exe`, `Kasa-mac.zip`, `kasa-py.zip`,
   `SHA256SUMS.txt` і опублікує випуск. Якщо версія в коді не збігається з тегом або такий випуск
   уже є — збирання зупиниться.

## Структура
| Файл | Що робить |
|---|---|
| `checkbox_web.py` | веб-інтерфейс і сервер каси (точка запуску) |
| `checkbox_app.py` | API Checkbox, локальна база SQLite, консольна версія |
| `goods_csv.py` | експорт/імпорт товарів у CSV, файл номенклатури Checkbox |
| `kasa_update.py` | оновлення з випусків GitHub |
| `mac/` | збирання «Каса.app» для macOS |
| `win/Зібрати exe.bat` | ручне збирання `Kasa.exe` на Windows |

Журнал роботи: `logs/kasa.log` у папці даних (шлях видно в налаштуваннях).
